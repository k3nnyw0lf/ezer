# Code of conduct

Be decent. Assume good faith.

That is genuinely the whole policy, spelled out:

- Critique code and ideas, not people. "This required field kills adoption" is a great comment;
  guessing at why someone wrote it is not.
- Newcomers asking basic questions are welcome. Everyone here was once the person who did not
  know what a comparative rater was, or what a git rebase was — this project needs both kinds
  of knowledge and nobody arrives with both.
- No harassment, no slurs, no personal attacks, no dogpiling. Disagreements about the contract
  get settled with evidence from real carrier behaviour, not volume.
- Reviews may take a few days; this project is run by people with day jobs at insurance agencies.

If someone's behaviour is making this project worse, email **ken@wolfsurety.com**. Reports are
read by a human, kept confidential, and acted on — from a conversation up to removal from the
project for repeated or serious violations.
